# Treinamento APIM Axway

## Introdução 
O objetivo deste workshop e apresentar uma visão geral da plataforma de API 
Management da Axway.
Os laboratórios serão realizados a partir de ambiente pré-instalado em nuvem, 
eventualmente pode ser necessário uma ferramenta de simulação de acesso tipo 
Postman (https://www.postman.com/downloads/) para uma validação de acesso 
a API.
